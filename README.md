# Personal Wiki

A personal knowledge base of research papers, concepts, and study notes, maintained with Claude Code and organized as an Obsidian vault.

Topics include Bayesian inference, information field theory, scientific machine learning, neural operators, generative models, and applied category theory. Paper summaries connect to shared pages covering definitions, methods, and theorems.
