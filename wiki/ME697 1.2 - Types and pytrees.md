# ME697 1.2 - Types and pytrees

**Summary**: Compilation needs static types, so the chapter reads JAX's transformations as typed higher-order functions (in Haskell notation), then introduces [[Pytree|pytrees]] as the typed containers that hold model parameters, and Equinox as the model library built on them.

**File**: `advanced-scientific-machine-learning/book/ml-software/types_and_models/`

---

## Topics
- **Why types (01)**: [[JIT compilation|jit]] specializes code to fixed shapes and dtypes; types make that explicit.
- **Python typing (02)**: annotations such as `List[int]` and `Callable[[int], int]`.
- **Haskell signatures (03)**: higher-order functions as types.
- **[[Pytree|Pytrees]] (04)**: nested lists, tuples, dicts, namedtuples; `tree_map`, `tree_reduce`, flatten/unflatten; Equinox modules.

## Key results
> [!definition] Signatures (03)
> ```
> map     :: (T -> U) -> [T] -> [U]
> filter  :: (T -> Bool) -> [T] -> [T]
> compose :: (U -> V) -> (T -> U)
>            -> (T -> V)
> vmap    :: (a -> b) -> ([a] -> [b])
> grad    :: ([a] -> a) -> ([a] -> [a])
> jacobian:: ([a] -> [a])
>            -> ([a] -> [[a]])
> hessian :: ([a] -> a) -> ([a] -> [[a]])
> fori_loop :: Int -> Int
>   -> ((Int, a) -> a) -> a -> a
> ```
> Currying: a two-argument function has type `T -> U -> V`.

> [!failure] jvp signature
> The book gives `jvp :: ([a] -> a) -> [a] -> [a] -> [a]`. Wiki note: `jax.jvp(f, primals, tangents)` returns the pair `(f(x), J v)`, so the result type is a tuple, not a single list.

- The gradient of a loss over a pytree of parameters is a pytree with the same structure, so one `tree_map` updates every leaf.
- Equinox was chosen over Flax and Haiku because an `eqx.Module` is itself a pytree.

## Examples
> [!example] Hand-built network (04)
> Parameters in a dict of weight and bias arrays. One [[Gradient descent]] step:
> ```
> tree_map(lambda x, g: x - 0.1*g,
>          params, grads)
> ```
> L2 penalty: `tree_reduce` of `tree_map(lambda x: x**2)`. `value_and_grad` returns loss and gradient together.

> [!example] Equinox SimpleNN (04)
> An `eqx.Module` with `eqx.nn.Linear` layers; `__call__` decorated with `@partial(vmap, in_axes=(None, 0))` so it maps over a batch.
