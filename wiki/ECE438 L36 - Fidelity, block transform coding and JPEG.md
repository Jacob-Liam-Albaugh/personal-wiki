## Review and notes

- Entropy $=-\sum_ip(a_i)\log p(a_i)$: the average amount of information learned when told the value of the symbol (the outcome of the event).
- Shannon's noiseless coding theorem: a code can achieve the entropy (using infinite blocks of symbols) but can never achieve lower.
- Huffman code construction maps a fixed number of symbols (for example, a block of $x_1x_2x_3$) into a variable number of bits.
