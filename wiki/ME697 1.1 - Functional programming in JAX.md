# ME697 1.1 - Functional programming in JAX

**Summary**: JAX only transforms pure functions, so the chapter starts with functional programming in plain Python, then covers the three transformations used everywhere later: `jit`, `vmap`, and explicit random keys.

**File**: `advanced-scientific-machine-learning/book/ml-software/functional_programming/`

---

## Topics
- **Primer (01)**: pure functions (no side effects, output depends only on input); `map`, `filter`, `reduce`; partial application and currying; function composition; decorators as functions taking functions.
- **[[JIT compilation]] (02)**: `jax.jit` traces a pure function once and compiles it with XLA.
- **[[vmap]] (03)**: write the function for one input, vectorize over a batch axis.
- **[[JAX random keys]] (04)**: no global seed; keys are split and passed explicitly.

## Key results
- Side effects inside a jitted function run only at trace time: a `print` fires on the first call, not later ones.
- Python loops are unrolled during tracing; long loops should be `lax.fori_loop`, `lax.while_loop` or `lax.scan`.
- Python `if` on a traced value fails; use `lax.cond` / `lax.switch`, or mark the argument static (`static_argnums`), which recompiles for every new value.
- `jit` and `vmap` compose as decorators: `@jit` over `@partial(vmap, in_axes=...)`.

## Examples
> [!example] RBF features with vmap (03)
> One radial basis function
> 23923\phi(x;c)=\exp\big(-\|x-c\|^2/\sigma^2\big)23923
> written for a single centre, then `vmap(rbf, in_axes=(None,0,None))` maps over a stack of centres. Same model as the [[Random features model]].

> [!example] Random walk with scan (04)
> Split one key into many, then `lax.scan` over them to take 100,000 random-walk steps inside one compiled loop.

> [!example] Homework 1, problems 1-3 (source: homework/01_homework.ipynb)
> Fibonacci with tail recursion and no loops; `foldl` and its use for sum and product; Fibonacci again with `lax.scan` plus `jit`. See [[ME697 7 - Homework]].

> [!example] Homework 1, problem 4: logistic map
> $x_{n+1}=r\,x_n(1-x_n)$ vectorized over $r$ and $x_0$ with `vmap`; output shape (1000, 100, 10000); period-doubling plot.
