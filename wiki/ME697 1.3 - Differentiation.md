# ME697 1.3 - Differentiation

**Summary**: Three ways to get derivatives on a computer: finite differences, symbolic differentiation, and [[Automatic differentiation]]. Only autodiff is exact, cheap and handles loops and branches; reverse mode gives a full gradient for the cost of one extra pass.

**File**: `advanced-scientific-machine-learning/book/ml-software/differentiation/`

---

## Topics
- **Numerical (01)**: forward difference
  $$f'(x)\approx\frac{f(x+h)-f(x)}{h}$$
  Truncation error falls with $h$, round-off error grows as $h\to0$; a log-log error plot shows an optimal $h$. A gradient in $n$ dimensions costs $n+1$ function evaluations.
- **Symbolic (02)**: sympy expression trees. Cannot differentiate through loops or conditionals, and expressions swell: nested softplus $\log(1+e^{wx+b})$ grows quickly.
- **Autodiff (03)**: computational graph, chain rule as a product of Jacobians, forward vs reverse mode.
- **JAX grad (04)**: `jax.grad` on a regression loss.

## Key results
- Forming Jacobians explicitly costs too much memory; autodiff only ever multiplies by them (JVP or VJP).
- Forward mode: one pass per input direction, so $n$ passes for a gradient.
- Reverse mode: one pass per output, so one pass for a scalar loss. This is backpropagation; it stores the intermediates of the forward pass.
- A general DAG reduces to a chain with a fanout map $x\mapsto(x,x)$, Jacobian $[I;I]$. Example: $f(x)=x^2+x$ is `add ∘ (sqr, id) ∘ fanout`.
- Pointer given: Matt Johnson's Autodidact, a small autodiff implementation.

## Examples
> [!example] RBF regression with grad (04)
> Generalized linear model on [[Random features model|RBF features]], squared loss. `grad(loss, argnums=0)` differentiates in the weights; `argnums=(0, 1, 2)` returns a tuple of gradients. A plain [[Gradient descent]] loop fits it.
