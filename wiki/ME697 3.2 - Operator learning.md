# ME697 3.2 - Operator learning

**Summary**: A short reading-and-tutorial chapter. The takeaway is that scientific models are operators (functions of functions), and neural networks can learn them directly. The book assigns the DeepONet and FNO papers and links two external JAX tutorials; it contains no derivations of its own.

## Topics
- **Intro**: scientific models are operators, i.e. functions that take functions as inputs.
- **01 Reading**: two papers to read, [[DeepONet (Lu 2021)]] and [[FNO (Li 2021)]].
- **02 DeepONet**: a link to a JAX tutorial that learns the antiderivative operator (Ceyron, `simple_deepOnet_in_JAX`). The notebook has no code of its own.
- **03 FNO**: a link to a JAX tutorial that learns the 1D Burgers equation (Ceyron, `simple_FNO_in_JAX`). The notebook has no code of its own.

## Key results
> [!definition] Operator (intro, and 3.1)
> A map from a function space to a function space, e.g. the PDE solver
> $$S:(a,f,g)\mapsto u$$
> of [[ME697 3.1 - Functional inputs]]. Learning $S$ directly avoids discretizing the inputs first and then fighting the curse of dimensionality there.

- **DeepONet** (assigned reading; Wiki note: standard description, not given in this chapter): a branch network encodes the input function sampled at sensor points, a trunk network encodes the output location, and their inner product gives the output value. Based on the universal approximation theorem for operators. See [[DeepONet]], [[Universal approximation for operators]].
- **FNO** (assigned reading; Wiki note: standard description, not given in this chapter): a stack of layers that mix a pointwise linear map with a Fourier-space multiplication on truncated modes, so the operator is learned on a grid-independent footing. See [[FNO]], [[Discretization invariance]], [[Kernel integral operator]].
- Both papers are instances of a general [[Neural operator]]; compare [[LNO]] and the PCA-based [[PCA-Net]].
