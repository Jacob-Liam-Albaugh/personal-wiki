# ME697 6.2 - Filtering and smoothing

**Summary**: Reconstruct the hidden state of a partially observed stochastic dynamical system from noisy data. The notebooks use a bootstrap particle filter and smoother on a stochastic Duffing oscillator, built with the lab's `dax` package.
**File**: `advanced-scientific-machine-learning/book/sinverse/fs/` (`02_filter.ipynb`, `03_smoother.ipynb`; `01_reading.md` has only the heading "Particle Filters")

---

## Topics
- Takeaway: filtering and smoothing reconstruct the state of a partially observed stochastic system (source: sinverse/fs/intro.md).
- Model class: [[Stochastic state-space model]], obtained by discretizing an SDE with [[Euler-Maruyama method]].
- [[Particle filter]] (bootstrap) for filtering; bootstrap smoother for smoothing.
- Package `dax` (PredictiveScienceLab/dax): `StateSpaceModel`, `EulerMaruyama`, `GaussianLikelihood`, `BootstrapFilter`, `BootstrapSmoother`, `ParticleMCMC`, `ExpectationMaximization`.
- Linear-Gaussian special case: [[Kalman filter]] (not covered by the notebooks).

## Key results

> [!definition] Stochastic Duffing oscillator (source: 02_filter.ipynb)

$$
\ddot x + \delta\dot x + \alpha x + \beta x^3
= \gamma\cos(\omega t) + \sigma\,\xi(t).
$$

Written as a 2D SDE for $(x,v)$ and discretized by Euler-Maruyama, the transition is Gaussian:

$$
p(x_t\mid x_{t-1},u_t) = N\big(\cdot\,,\ \mathrm{diag}(\sigma_x^2,\sigma_v^2)\,\Delta t\big).
$$

Only position is observed with Gaussian noise of standard deviation $s$.

Parameters: $\omega=1.2$, $\alpha=-1$, $\beta=1$, $\delta=0.3$, $\gamma=0.5$, $\sigma_x=0.01$, $\sigma_v=0.05$, $s=0.1$, $\Delta t=0.1$, prior $N(0,I)$.

**Filtering distribution** $p(x_t\mid y_{1:t})$: propagate particles through the transition, weight by the likelihood of $y_t$, resample.

**Smoothing distribution** $p(x_t\mid y_{1:T})$: conditions on all data, so it is at least as sharp as the filter.

## Examples
> [!example] Filter
> Bootstrap filter with 10,000 particles, $t\in[0,40]$, first 200 steps used for training. The credible interval shrinks as data arrive. Predicting forward from the last filtered state stops tracking the true state after a while (source: 02_filter.ipynb).

> [!example] Smoother
> Bootstrap smoother with 1000 trajectories, $t\in[0,20]$. It beats the filter, especially for the hidden velocity at early times, and the gap grows with observation noise (source: 03_smoother.ipynb).

> [!example] Homework
> Nothing in homework 1-7 targets filtering; Homework 7 covers deterministic data-driven dynamics, see [[ME697 7 - Homework]].

## Connections
- Models come from [[ME697 6.1 - Stochastic differential equations]]; parameters are then learned in [[ME697 6.3 - Calibration of stochastic models]].
- The particle filter gives an unbiased likelihood estimate that [[Particle MCMC]] uses.
- Smoothing is the SDE analogue of the field-level smoothing in [[ME697 IFT.3 - Physics-informed information field theory]], where the prior over trajectories is biased by the physics.
- Deterministic counterpart: [[SINDy]] and [[ME697 DMD - Dynamic mode decomposition]].

**Wiki note (book oddities)**:
- The Duffing text writes $dX_1=X_2$ without $dt$, and gives the control as $\omega\cos(\cdot)$ while the code uses $\gamma\cos(\omega t)$.
