# ME697 5.2 - Parametric PINNs

**Summary**: Learn the whole map from PDE parameters to solution in one training run. This is where PINNs can beat a classical solver. The example is a Poisson problem with an amplitude parameter, solved with a branch-trunk ansatz.
**File**: `advanced-scientific-machine-learning/book/pinns/parametric/` (`parametric_example.ipynb`; `physics-informed_nops.ipynb` is a title-only stub)

---

## Topics
- Module takeaway: PINNs can build surrogates of scientific models given as ODEs or PDEs (source: pinns/intro.md).
- Why parametric: for a single solve a numerical method is cheaper; for a family of solves, one network trained over the parameter distribution amortizes the cost.
- Ansatz built from learned basis functions (a branch-trunk split, as in [[DeepONet]]).
- Loss averaged over the parameter density.
- Physics-informed neural operators: only a stub in the book.

## Key results

> [!definition] Parametric PINN ansatz (parametric_example.ipynb)
> For parameters $\xi$ with density $p(\xi)$:

$$
N(x,\xi;\theta) = \sum_{i=1}^{m} b_i(\xi;\theta)\,\phi_i(x;\theta).
$$

The $b_i$ ("branch") depend on $\xi$ only. The $\phi_i$ ("trunk") are learned basis functions of $x$. See [[Parametric PINN]].

**Loss.** Average the per-parameter PINN loss over the parameter law:

$$
\mathcal L(\theta) = \int \mathcal L_\xi(\theta)\,p(\xi)\,d\xi.
$$

Minimize with [[Adam]] using unbiased gradient estimates: draw a few $\xi$ and a fresh set of collocation points each step.

## Examples
> [!example] Poisson with amplitude parameter
> On $[0,1]^2$ solve
> $$
> -\Delta u = 2\pi^2\,\xi\,\sin(\pi x)\sin(\pi y).
> $$
>
> The exact solution is $u=\xi\sin(\pi x)\sin(\pi y)$ (checked with sympy).
> - Boundary: $u = x(1-x)y(1-y)\,N$, class `EnforceDirichletZeroBoundarySquare`.
> - Model `ParametricModel`: $m=10$ branch MLPs (width 32, depth 3, scalar in and out) and 10 trunks (32 [[Fourier features]] followed by an MLP).
> - Training: 128 collocation points and 2 values of $\xi$ per step, 1000 iterations, about 2.5 minutes.
> - Result "pretty good"; more iterations would fit better (source: parametric_example.ipynb).

> [!example] Homework 7 problem 3, part C
> Parametric neo-Hookean problem with the applied displacement $\delta\in[0,0.5]$ as network input, see [[ME697 7 - Homework]].
