# ME697 2.3 - Surrogates

**Summary**: A [[Surrogate model]] replaces an expensive simulator by a cheap statistical model so that Monte Carlo, [[Sensitivity analysis]] and optimization become affordable. The chapter gives the 7-step workflow, the three standard model families, and a running example (a finite-element model of subcutaneous autoinjectors) fitted with an MLP, an exact [[Gaussian process]], and a sparse variational GP.

**File**: `advanced-scientific-machine-learning/book/up/surrogates/`

---

## Topics
- **Intro**: surrogates are statistical models that let us propagate uncertainty by Monte Carlo through an expensive model.
- **01 Basics**: setup, workflow, model families, diagnostics.
- **02 NN surrogate**: MLP on the autoinjector data (Equinox + optax), parity plots, data-size convergence, Sobol indices from the surrogate.
- **03 GP surrogate**: exact GP in `tinygp`, hyperparameters by marginal likelihood, standardized errors, one GP per output.
- **04 GP with large data**: exact GP fails (crashes) on the full set; sparse variational GP with inducing points in `gpjax`.

## Key results
> [!algorithm] Surrogate workflow (01)
> 1. Training data from the expensive model $f$ at a space-filling design ([[Latin hypercube sampling]] or Sobol sequence).
> 2. Separate validation data, also space-filling.
> 3. Choose a model: polynomial regression / generalized linear model, GP regression, or a neural network.
> 4. Train.
> 5. Validate (mean squared error); if poor, add data and retrain.
> 6. Test on a third set with more diagnostics; if poor, change the model (step 3).
> 7. Use it: prediction, optimization, sensitivity analysis, uncertainty propagation, later inverse problems.

- **Generalized linear model**: $\hat f(x)=\sum_iw_i\phi_i(x)$; polynomials, radial basis functions, [[Polynomial chaos]]. Train by least squares, maximum likelihood, or posterior over $w$ (sampling or VI; the course prefers the last).
- **GP regression**: prior $f\sim\mathrm{GP}(m,k)$, usually zero mean; squared-exponential kernel (infinitely differentiable); hyperparameters by maximizing the marginal likelihood. Cost is cubic in the number of training points, impractical beyond about 5,000. Remedies: sparse GP with inducing points (Hensman et al. 2015), Kronecker structure for grid inputs with separable kernels (Bilionis et al. 2013), GPyTorch scalable-GP list.
- **Diagnostics**: parity plot and RMSE check the mean. For GPs, standardized errors check the uncertainty:
$$e_i=\frac{y_i-m(x_i)}{\sigma(x_i)}$$
  Histogram, QQ plot (normality), residual plot (homoscedasticity).
- **Preprocessing (02)**: standardize inputs; log-transform skewed outputs, then standardize.
- **Data size**: the MLP (5 hidden layers of 100, Adam $10^{-3}$, 5000 iterations, batch 128) is good from about 2,000 points; at 500 points it already looks reasonable. Exact GPs need only a few hundred points for most outputs; needle displacement needs more data or built-in inductive bias (03).
- **Exact GP failure (04)**: inversion of the $n\times n$ covariance is $O(n^3)$, so the full training set crashes the kernel. The sparse variational GP maximizes the [[ELBO]] and inverts only the $m\times m$ inducing covariance, cost $O(bm^2+m^3)$ for minibatch $b$ and $m=100$ inducing points.
- **Use**: Sobol indices from the surrogate show injection time is very sensitive to viscosity and needle diameter, somewhat to needle length and spring force, and insensitive to the rest. The book stresses this would not have been feasible with the true model (02, 03). See [[Sobol indices]].

## Wiki notes
- In 03 the exact-GP hyperparameters are fitted by Adam on minibatches (`X[idx]`). The exact marginal likelihood of a random subset treats the subset as the whole dataset, so this is a biased stochastic objective, not the standard unbiased minibatch estimate used for sparse variational GPs. The book does not comment on this.
- Step 5 of the workflow loops back to step 4 ("retrain") while adding data; this is fine, just note that the validation set is reused across iterations, which is why a separate test set (step 6) is kept.
