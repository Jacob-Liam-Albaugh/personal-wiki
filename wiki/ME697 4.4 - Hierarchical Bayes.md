# ME697 4.4 - Hierarchical Bayes

**Summary**: A [[Hierarchical Bayesian model]] ties many related inverse problems together through shared population parameters. The chapter's example is "cars on a bumpy road", sampled with NUTS, followed by an amortized-VI example for inverse kinematics.

**File**: `advanced-scientific-machine-learning/book/inverse/hbayes/`

## Topics
- **01 Basics**: "TODO: Write me." (empty).
- **02 Cars on a bumpy road**: each car $i$ is a damped oscillator $\ddot x+2\zeta\dot x+\omega^2x=0$ with an analytic solution. Individual $(\zeta_i,\omega_i)$ have lognormal conditional priors given population parameters $(\mu_\zeta,\tau_\zeta,\mu_\omega,\tau_\omega)$.
  - Population distribution: $p(\zeta,\omega)=\int p(\zeta,\omega|\theta_{pop})p(\theta_{pop})d\theta_{pop}$.
  - A Numpyro model is converted to a Blackjax log density; NUTS warmup uses tempering with a cosine schedule and chain pruning.
  - Population-level prediction: the probability of crossing a threshold on a new bump.
  - Both centered and non-centered parameterizations appear in the code.
- **03 Bad posterior geometry**: stub (title only).
- **04 Amortized VI**: inverse kinematics, see below.

## Key results
- Wiki note: the population-level prediction integrates over the population parameters and the individual parameters, so it carries between-car and within-car uncertainty.
- Code ground truth: $x_0=3.5$; $p\sim\mathcal N((-1.5,1.0),[,[0.1,0.07],[0.07,0.1],])$; $\omega=\exp(f(p_2))$ with $f(x)=x+0.3\cos(2(x-1))$. Settings: 20 time points on $[0,4]$, 100 individuals, noise 0.1.

## Examples
> [!example] Inverse kinematics with amortized VI (04)
> A 4-DOF arm (slider height plus three joint angles, link lengths $(0.5,0.5,1.0)$, noise variance $10^{-4}$) with prior $\mathcal N(0,\mathrm{diag}(1/16,1/4,1/4,1/4))$. The guide is
> $$q_\phi(\xi|y)=\mathcal N(\mu_\phi(y),L_\phi L_\phi^T)$$
> with three MLPs (2-20-10-out, relu; diagonal by softplus plus $10^{-6}$). Trained on prior samples with noise: Adam, learning rate 0.01 (times 0.1 at step 5000), 10000 steps, 5 particles, batch 30. The text discusses non-identifiability, mode seeking, and the variational gap versus the amortization gap. See [[Amortized VI]] and [[Amortized VI for inverse problems (Karumuri 2024)]].

> [!failure] Wiki notes: text versus code in hbayes/02
> - Text says 30 cars; code has `N_INDIVIDUALS=100`. Text says 20 snapshots per car and also $M$ time points.
> - Text prior $\mu_\zeta\sim N(-1,1)$; code uses $N(-2,1)$.
> - Threshold is $x=-3$ cm in one place and $-2$ cm in the last paragraph; code uses $-3$. Units of $x_0\in[0,5]$ switch from inches to cm.
> - "Exponential(10)" is ambiguous (rate or scale); Numpyro uses a rate.
